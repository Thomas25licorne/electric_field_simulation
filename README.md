# electric_field_simulation

## Overview

The following is the code used to simulate the behaviour of an electric field in specific settings with objects of different charges. The output is a 2D map and is entirely done in python.

## Set up


Ensure you have python downloaded. 

The following libraries are required:
- pygame
- numpy
- matplotlib

To install the libraries, run the following command in your terminal:


pip install pygame numpy matplotlib

or if you are using a Mac,


pip3 install pygame numpy matplotlib

## Execution

Run the file main.py.

Then, using the interactive buttons, select the charge and shape and click on the map where you would like the shapes to appear. Note that to add a shape to the map, you need to left click twice: once for each opposite corners of the shape, and center to radius for the disk.
